🤖 Navigateur IA Studio + Analyse de fichiers

Module dédié à Google AI Studio : un navigateur intégré pour utiliser AI Studio sans quitter le logiciel, un import de gros fichiers .json d'annonces, et une bibliothèque de prompts génériques et réutilisables.

❓ Comment utiliser ce module ?
  1. Scraper les annonces depuis l'onglet « 🚀 Scraper ».
  2. Récupérer le fichier .json contenant les annonces (depuis l'Historique Jobs ou l'Explorateur).
  3. Glisser-déposer ce fichier .json dans la zone d'import ci-dessous.
  4. Choisir le type d'analyse (prompt) et le domaine (hardware, livres, smartphones…).
  5. Copier / utiliser le prompt généré (le bouton « Copier » le met dans le presse-papiers).
  6. Envoyer le fichier et le prompt dans AI Studio via le navigateur intégré.
  7. Récupérer les résultats directement dans AI Studio.

Ce module ne remplace pas AI Studio : il facilite énormément la préparation des données, des prompts et leur utilisation.

📥 Envoyer le fichier .json à AI Studio

Pour analyser un fichier d'annonces, glissez-déposez-le directement dans la zone de chat de Google AI Studio (la fenêtre du navigateur à droite), comme dans un Chrome normal. Le fichier est envoyé à AI Studio, pas stocké par ce module.

💡 Le module ne sert qu'à préparer le prompt ci-dessous — copiez-le puis collez-le dans le chat AI Studio avec votre fichier.
