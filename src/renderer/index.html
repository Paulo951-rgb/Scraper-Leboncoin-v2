🤖 Navigateur IA Studio + Analyse de fichiers

Module dédié à Google AI Studio : un navigateur intégré pour utiliser AI Studio sans quitter le logiciel, un import de gros fichiers .json d'annonces, et une bibliothèque de prompts génériques et réutilisables.

❓ Comment utiliser ce module ?
  1. Scraper les annonces depuis l'onglet « 🚀 Scraper ».
  2. Ouvrir les jobs (bouton 📂 Ouvrir le dossier des jobs) pour retrouver le fichier .json.
  3. Démarrer Ollama sur votre PC puis cliquer « 🔄 Lister » pour vérifier la connexion et choisir le modèle.
  4. Décrire l'objectif de l'analyse + choisir le domaine (hardware, livres, smartphones…).
  5. Générer le prompt par l'IA locale (bouton « ✨ Générer par IA locale ») puis le copier.
  6. Envoyer le fichier .json et le prompt dans AI Studio : glisser-déposer le fichier dans le navigateur intégré (à droite), coller le prompt. Pour la connexion Google, utiliser 🔑 Se connecter ou ↗ (Chrome externe).
  7. Récupérer les résultats directement dans AI Studio.

Ce module ne remplace pas AI Studio : il facilite énormément la préparation des données, des prompts et leur utilisation.

📥 Envoyer le fichier .json à AI Studio

Pour analyser un fichier d'annonces, glissez-déposez-le directement dans la zone de chat de Google AI Studio (la fenêtre du navigateur à droite), comme dans un Chrome normal. Le fichier est envoyé à AI Studio, pas stocké par ce module.

🔑 Connexion Google : le navigateur intégré (webview) est bloqué par Google pour la connexion. Deux options :

  • cliquez 🔑 Se connecter (fenêtre dédiée, masque Electron) — marche parfois ;
  • sinon cliquez ↗ dans la barre du navigateur pour ouvrir AI Studio dans votre Chrome externe (connexion garantie), puis revenez ici pour la génération du prompt.

🎨 Apparence

🚀 Scraping

⚠️ « Rapide » n'extrait pas les descriptions détaillées (le titre + prix suffisent). Pour l'analyse de marché IA, préférez « Équilibré » ou « Prudent ».
Plus bas = plus rapide, plus haut = plus discret. Recommandé : 800-1500ms.

🧠 Analyse IA Locale

Nombre d'annonces analysées en parallèle par l'IA. Plus élevé = plus rapide, mais demande plus de RAM/VRAM. Recommandé : 3-5 pour CPU, 5-10 pour GPU.

🧹 Maintenance

Les fichiers .har plus anciens que ce nombre de jours sont supprimés au démarrage.
Si coché, les dossiers de jobs plus anciens que ce nombre de jours sont supprimés au démarrage (HAR + résultats inclus).
Les fichiers de log plus anciens que ce nombre de jours sont purgés automatiquement (rotation quotidienne).
